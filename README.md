# Music Pro - Bodega Principal

## Instalación y ejecución

1. Instalar dependencias:
```
pip install -r requirements.txt
```

2. Ejecutar el servidor:
```
python manage.py runserver
```

3. Abrir en el navegador:
```
http://127.0.0.1:8000/
```
